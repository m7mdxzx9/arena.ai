# Learning System

## Preserved learning loop

The campaign still follows the original progression:

1. **Teach** — concise concept explanation and analogy.
2. **Visualize** — interactive widgets backed by real local calculations.
3. **Predict** — learner commits before seeing an experiment.
4. **Experiment** — scikit-learn or NumPy runs with saved configuration and metrics.
5. **Explain** — reflection and diagnostic feedback.
6. **Review** — adaptive questions and spaced repetition.

Missions, boss battles, Code Dojo, achievements, equipment gates, XP and ranks are not replaced by the personal lab. Open Lab is a parallel non-linear path; campaign progress remains meaningful.

## Progression

- Attempts update concept mastery through the BKT model.
- XP events are durable and rank promotion is derived from total XP.
- Equipment unlocks from prerequisite concept mastery.
- Missions and bosses persist state independently.
- Free Play changes access, not recorded mastery or completion.
- Reflections, experiment notes and mistake reviews remain player-owned records.

## Personal laboratory loop

The new loop is deliberately evidence-driven:

1. Upload or select a bounded dataset.
2. Inspect schema, missingness, duplicates and leakage warnings.
3. Choose task, target, features, preprocessing and model.
4. Train a real engine with an explicit seed and device.
5. Inspect curves, metrics, confusion matrix, mistakes and runtime warnings.
6. Save the run/checkpoint.
7. Send diagnosed mistakes to spaced review.
8. Build an evaluation set or portfolio case study from the saved evidence.

## Honest system labels

| Surface | Label and behavior |
|---|---|
| NumPy Neural Lab | Educational, real NumPy training, intentionally transparent |
| RAG Learning Simulator | Educational deterministic simulator using bundled corpus |
| Agent Security Simulator | Deterministic educational state machine |
| PyTorch & CNN Lab | Real optional PyTorch optimizer/backprop execution |
| Personal RAG | Real uploaded-document retrieval; extractive fallback is identified |
| Real Agent Lab | Real optional local-model decisions with controlled tools |
| AI Tutor offline mode | Curated deterministic content |
| AI Tutor local mode | Real optional Ollama generation |

No simulated result is presented as provider/model output.

## Learner evidence

Saved experiment runs contain setup, result, summary, context, timestamp and notes. PyTorch runs add device/version/seed/curves and a locally generated checkpoint. Evaluation runs record each deterministic rule and result. Portfolio entries retain a source-run snapshot so later edits do not sever provenance.

## Offline-first guarantee

Campaign, review, built-in datasets, scikit-learn labs, NumPy NN, simulators, offline tutor, mistake journal and deterministic evaluation work without a network or paid service. Ollama features are additive and fail with an explicit unavailable state.
